# Design Principals
1. Keep it simple. Small methods used for a single task
2. Code should be self documenting. Who cares if a method or variable's name is long, if it explicitly describes what it's doing
3. Build generically 
4. Have an easy to navigate structure
5. Don't repeat yourself
